# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-16

### Added
- Initial release of @xem.email/sdk
- Email sending functionality via `xem.email.send()`
- Support for HTML and template-based emails
- Template data support for dynamic content
- CC, BCC, and Reply-To functionality
- Email scheduling with `scheduleAt` parameter
- Test mode for validating emails without sending
- Custom email provider support
- Full TypeScript support with comprehensive type definitions
- Error handling and validation
- API key authentication via constructor or `login()` method
- Configurable base URL and timeout
- Complete documentation and examples
