## [v1.0.0] – 2025-09-03
### Added
- **First stable release.**  
- Multi-provider email sending (SendGrid, Mailgun, SES, or any SMTP).
- Flexible HTML/CSS templates with dynamic data, A/B testing, and mobile previews.
- RESTful API for all core features—user management, email sending, analytics.
- Audience Insights API: fetch click rate, open rate, audience growth, segmentation data.
- Foundation for AI-powered optimization: send-time prediction, smart content recommendations (coming soon).
- Rule-based campaign automation with performance tracking and triggers.

### Changed
- Full documentation published at [docs.xem.email](https://docs.xem.email/).

***

## [v0.7.0] – 2025-08-20
### Added
- Workflow builder: create automated multi-step and trigger-based campaigns.
- API endpoint to fetch user and campaign engagement stats.
- Improved SMTP provider fallback logic.
- Early-stage analytics dashboard for campaign metrics.

### Changed
- Upgraded email validation and error handling for sending API.
- Enhanced onboarding with new Quick Start guides.

***

## [v0.4.0-beta] – 2025-07-31
### Added
- Basic support for multiple SMTP providers.
- Simple HTML template uploads.
- User authentication and token-based access for API.

### Changed
- Refined developer onboarding experience.
- Initial API documentation released.

***

## [v0.2.0-alpha] – 2025-07-10
### Added
- MVP: Send transactional and marketing emails via a single SMTP.
- User registration and login flow (API only).
- Minimal admin dashboard.

***
