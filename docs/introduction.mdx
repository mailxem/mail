Xem is an open-source email marketing suite. It brings campaigns, recurring newsletters, visual automations, signup forms, a contact CRM, a shared inbox and analytics into one app. It sends through Amazon SES or any SMTP provider, so sending costs what your provider charges rather than a fee per subscriber.

You can use the hosted app at [app.xem.email](https://app.xem.email) or run Xem on your own server under the GPL-3.0 licence. The source is on [GitHub](https://github.com/mailxem/mail).

## What Xem includes

| Area | What you can do |
| --- | --- |
| Campaigns and newsletters | Send one-off campaigns or recurring newsletters with a cadence and timezone, and publish sent editions in a public web archive |
| Templates | Edit 200+ templates built from native editor blocks, with AI help for drafts |
| Automations | Build visual journeys triggered by events such as opens and clicks |
| Audience | Manage lists, tags, signup forms and a contact CRM with notes and stages |
| Inbox | Read and reply to mail from connected mailboxes in a shared inbox |
| Analytics | See delivery separately from opens and clicks, with growth and send-time insights |
| Sending | Use Amazon SES, Gmail, Outlook or any SMTP server; the hosted app also offers managed sending |
| Integrations | Use API keys, webhooks and an MCP server for AI assistants |

## How sending costs work

Xem does not charge per email. Your provider does. Through Amazon SES that is \$0.10 to \$0.16 per 1,000 emails, so a weekly newsletter to 10,000 people costs about \$4.00 to \$6.40 a month to send. The [Amazon SES guide](/guides/amazon-ses) covers setup and pricing plans.
